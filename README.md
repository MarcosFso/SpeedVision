# 🏎️ SpeedVision

O **SpeedVision** é um sistema de monitoramento automotivo e estimativa de velocidade desenvolvido em equipe. O projeto utiliza Visão Computacional para processar o vídeo de uma rodovia, identificar os veículos em movimento e calcular uma estimativa de velocidade em tempo real, simulando o funcionamento de um radar eletrônico.

Os dados processados pelo algoritmo são integrados e exibidos em uma interface web moderna e intuitiva por meio de uma API.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

### **Back-End & Visão Computacional**
*   **Python:** Linguagem base para o processamento de dados e lógica principal do radar.
*   **OpenCV / Bibliotecas de Visão Computacional:** Utilizadas para a manipulação do vídeo, detecção de movimento e rastreamento dos veículos.

### **Front-End & Integração**
*   **HTML5 & CSS3:** Estruturação e estilização da interface visual do sistema.
*   **JavaScript (JS):** Responsável pelo dinamismo da página, consumo da API e atualização dos dados na tela em tempo real.

---

## 🚀 Principais Funcionalidades

*   **Processamento de Vídeo:** Leitura e análise quadro a quadro do fluxo de veículos em uma rodovia.
*   **Simulação de Radar:** Cálculo lógico para estimar a velocidade dos carros detectados.
*   **Interface em Tempo Real:** Exibição dos dados coletados em um painel web limpo e responsivo.
*   **Consumo de API:** Integração transparente entre o script de inteligência em Python e a interface de usuário no Front-End.

---

## 🎯 Objetivo do Projeto

Este projeto foi construído com o propósito de aplicar conceitos práticos de lógica de programação, manipulação de arquivos de mídia, desenvolvimento web e comunicação entre sistemas (Back-End e Front-End), simulando um desafio real de engenharia de software e IoT.
